# کلانتر — نسخه سه‌نفره ناشناس

این پروژه مستقل از نسخه دو نفره است. سه کلید ورود ناشناس (`person1`, `person2`, `person3`) به یک اتاق مشترک متصل می‌شوند.

## امکانات
- هویت‌نمایی عمومی فقط با عبارت «ناشناس» در چت و نمای مشترک
- چت سه‌نفره با متن، عکس، صدا و فایل
- صفحه «حالم الان» با پنج احساس: حالم خوب نیست، حالم خوبه، خیلی خوشحالم، ناراحتم، دلگیرم
- صفحه «الان چی لازم دارم؟» با آرامش، حواس‌پرتی، حرف زدن، انرژی، تنهایی و حالت «بکش و نکش» برای مرتب‌سازی
- شمارش‌های مشترک بدون نمایش شناسه کاربر
- بازی‌های کوتاه و بی‌پایان محلی برای سرگرمی/آرام‌سازی
- بخش رسانه مشترک برای عکس، صدای ضبط‌شده و آهنگ
- دفتر مشترک متنی
- تم مشکی با آیکون‌های خاکستری و رنگ‌های بنفش/قرمز/آبی
- پس‌زمینه یکپارچه پروژه در تمام صفحات

## اتصال Flutter
برای بسته انتشار، آدرس Railway را با این دستور داخل برنامه قرار بده:

```bash
flutter build apk --release --dart-define=KALANTAR_API_URL=https://YOUR-KALANTAR-RAILWAY.up.railway.app
```

در صورتی که آدرس در build تعریف نشده باشد، از صفحه ورود/تنظیمات می‌توان آن را یک‌بار وارد کرد.

## Railway
راهنمای متغیرها در `RAILWAY_THREE_PERSON_VARIABLES.env` و راهنمای فارسی در `THREE_PERSON_RAILWAY_SETUP_FA.md` قرار دارد.
برای ماندگاری عکس/صدا/آهنگ، روی سرویس سرور Railway یک Volume بساز و آن را روی `/data/media` mount کن.
